FATADS — улучшенный демонстрационный лендинг

Файлы:
- index.html — структура сайта
- style.css — оформление и адаптивная версия
- script.js — меню, popup, форма, чат, cookie и кнопка наверх

Запуск:
1. Распакуйте папку FatAds_Pro.
2. Откройте index.html в браузере или запустите через Live Server в VS Code.
3. Для редактирования меняйте HTML, CSS и JS отдельно.

Важно:
Форма и чат работают как демонстрация на стороне браузера. Они не отправляют данные на сервер.
Для реальных заявок подключите backend (например, PHP + SQLite/MySQL) и API поддержки.
Показатели на графике и в таблице — демонстрационные, не реальные данные сети.
